Step 1: Set Up Your Supabase Database

1
Create a Supabase Project (if you don't have one)

Visit supabase.com and click "Start Project"

  • Sign up or log in
  • Create a new project
  • Save your project URL and API Key (you'll need these)
2
Run the Database Setup SQL

Your database schema is already prepared. Here's what to do:

  1. Open your Supabase project dashboard
  2. Click "SQL Editor" in the left sidebar
  3. Click "New Query"
  4. Open the file supabase-setup.md in your website folder
  5. Copy the entire SQL code from that file
  6. Paste it into the Supabase SQL Editor
  7. Click "Run"

Result: All tables created automatically (clients, bookings, services, quote_requests)

Step 2: Verify Website Files

You now have these new files in your website folder:

  • supabase-config.js – Shared Supabase configuration (pre-configured)
  • supabase-setup.md – Database setup instructions
  • booking.html – Booking form with live quote calculator
  • dashboard.html – Real-time booking dashboard
  • quote.html – Standalone quote calculator
  • setup.html – This guide

✓ All files are pre-configured with Supabase credentials – no manual input needed!

Step 3: Update Navigation Links

Add links to the new pages in your existing HTML files:

In your index.html, Services.html, Contact.html, and about.html:

Find the nav links section and update:

<li><a href="booking.html">Book</a></li>
<li><a href="dashboard.html">Dashboard</a></li>
<li><a href="quote.html">Quote</a></li>
✅ The booking.html, dashboard.html, and quote.html files already have the correct navigation links included!

Step 4: Test Everything

1
Test the Booking Form
  1. Open booking.html in your browser
  2. Fill out a test booking form
  3. Click "Request Appointment"
  4. Check your Supabase Dashboard → Tables → bookings table
  5. Verify the booking appears in the table
2
Test the Dashboard
  1. Open dashboard.html
  2. View all bookings in real-time
  3. Test filters: All, Pending, Confirmed, Completed
  4. Try updating a booking status or deleting one
3
Test the Quote Calculator
  1. Open quote.html
  2. Select different services
  3. Add optional services (After-Hours, Rush, Additional Signers)
  4. Verify price updates instantly
  5. Click "Book with This Quote" to redirect to booking form

🔧 Troubleshooting

Bookings not saving?

  • Check browser DevTools Console (F12) for error messages
  • Verify Supabase API credentials in supabase-config.js
  • Ensure your Supabase project is active
  • Check that the bookings table exists in Supabase

Dashboard not loading?

  • Make sure you completed the database setup (Step 1)
  • Try refreshing the page (F5)
  • Check if Supabase is accessible from your network

Quote calculator not calculating?

  • Open browser DevTools (F12) → Console tab
  • Look for JavaScript errors
  • Try resetting the calculator with the "Reset" button
